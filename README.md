### Germline Analysis with Pandas

In 2021 Toraason _et al_ described an analysis pipeline for processing images of _C. elegans_ germlines.
They describe a _linearization_ algorithm that "straightens out" the image of a germline and maps the locations of developing germ cells to locations on the straight line.

The code in this repo defines a Python module named `gawp` (Germline Analysis With Pandas) that has an updated version of GAP, the R script described in Toraason _et al_.  The functions defined in `gawp` can be called from command line scripts for batch processing or from Jupyter notebooks for exploration and visualization of single germlines

### Algorithm Overview

The input to the linearization algorithm is a spreadsheet, generated by Imaris, that has 

* the $x$ and $y$ coordinates of developing cells
* the coordinates of a series of line segments based on markers placed by the user that define a path through the center of the germline.

In this example there are 250 cells (yellow circles) and 17 markers (labeled A through Q):



<img src="https://github.com/conery/gawp/raw/main/docs/images/germline.png" width="400">

The algorithm maps each cell to the center line by finding the line segment closest to the cell and computing the intersection of a line through the cell and orthogonal to the segment.  This closeup view shows the intersections of the first few cells in the example data:

<img src="https://github.com/conery/gawp/raw/main/docs/images/intersections.png" width="200">

The final output is a new spreadsheet with the $x$ coordinates of cells range from 0 to 1, based on normalizing the locations where they map to the center line:

<img src="https://github.com/conery/gawp/raw/main/docs/images/linearized.png" width="600">

### Reference


Toraason, Erik, Victoria L. Adler, Nicole A. Kurhanewicz, et al. “Automated and Customizable Quantitative Image Analysis of Whole _Caenorhabditis Elegans_ Germlines.” Genetics 217, no. 3 (2021): iyab010. https://doi.org/10.1093/genetics/iyab010.

## Acknowledgments

GAWP makes extensive use of several data science libraries:

* the key steps are all "reshaping" operations performed on [Pandas](https://pandas.pydata.org/docs/index.html) dataframes

* we use a Geometry package named [Shapely](https://shapely.readthedocs.io/en/stable/) to represent coordinates of cells and line segments representing a germline 

* the [GeoPandas](https://geopandas.org/en/stable/) library allows use to store Shapely objects in Pandas dataframes for efficient vectorized calculations 

* the notebooks use [Bokeh](https://docs.bokeh.org/en/latest/index.html#) for visualizing results
