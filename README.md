# GAWP

### Germline Analysis with Pandas

In 2021 Toraason _et al_ described an analysis pipeline for processing images of _C. elegans_ germlines.
They describe _linearization_ algorithm that "straightens out" the U-shaped germline and maps the locations of developing germ cells to a relative location on the stight line.

> _Images TBD_

The code in this repo defines a Python module named `gawp` (Germline Analysis With Pandas).

* the linearization algorithm is an updated version of the method in GAP, the R script described in Toraason _et al_. 

* the functions defined in the module can be called from command line scripts for batch processing or from Jupyter notebooks for exploration and visualization of single germlines

### Reference


Toraason, Erik, Victoria L. Adler, Nicole A. Kurhanewicz, et al. “Automated and Customizable Quantitative Image Analysis of Whole _Caenorhabditis Elegans_ Germlines.” Genetics 217, no. 3 (2021): iyab010. https://doi.org/10.1093/genetics/iyab010.

### Acknowledgements

GAWP makes extensive use of several data science libraries:

* the key steps are all "reshaping" operations performed on [Pandas](https://pandas.pydata.org/docs/index.html) dataframes

* we use a Geometry package named [Shapely](https://shapely.readthedocs.io/en/stable/) to represent coordinates of cells and line segments representing a germline 

* the [GeoPandas](https://geopandas.org/en/stable/) library allows use to store Shapely objects in Pandas dataframes for efficient vectorized calculations 

* the notebooks use [Bokeh](https://docs.bokeh.org/en/latest/index.html#) for visualizing results
