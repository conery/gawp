GAWP: Germline Analysis with Pandas

GAWP is a rewrite and extension of the original Germline Analysis Pipeline (GAP) from the Libuda Lab at the University of Oregon.1

Our main goal for developing a new script was that we wanted a version that was written in Python and that allowed users to run the code either from the command line or a Jupyter notebook. We also wanted to make it easier for users to adapt the script for new projects.

The result is a new organization based on plugins. GAWP has a set of independent modules that perform individual steps of the analysis pipeline. Before running GAWP, users create a configuration file that tells the system the plugins to use and thus which steps to run.

The configuration file specifies the sheets from the Imaris output that have the data to use, which columns on those sheets have the relevant data, and various other parameters. The end result is that no settings are "hard wired" into the code -- everything is defined in the configuration file. This should make it easier for new users in the future to run the code on their own data sets (and potentially make it easier to adapt to new data formats from different versions of Imaris).
